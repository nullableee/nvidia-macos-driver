# Результат замера v6

Источник: perf-20261030-002502-1134. Пользователь исправил collect-perf.sh;
его версия сохранена в исходниках с LC_ALL=C и проверена mock-Darwin тестом
на корректных и неполных счётчиках. Точная причина первоначальной ошибки
скрипта не установлена; её текст в сборе не сохранён.

20 секунд: 397 успешных CPU-копирований (19.85/с), 396 интервалов входа
performTransaction, средний интервал 50.9992 мс. В гистограмме 35 интервалов
28–40 мс и 361 >=40 мс; интервалов <28 мс в этом окне нет.

Средние времена:
- fence: 0.3152 мс;
- подготовка актуального IOSurface / pageoff: 2.8677 мс;
- CPU copy: 2.1409 мс;
- весь performTransaction: 5.3346 мс.

VBlank: настроено 5.9772 мс, наблюдаемый средний интервал 5.9773 мс
(около 167 программных событий/с). Это программный таймер, не точный
аппаратный timestamp матрицы. Новых GPU timeouts, iop failures, copy skips
за измеренный интервал — 0. Максима с начала загрузки включают другие нагрузки.

Пауза между вызовами драйвера значительно больше времени его обработчика.
Это не подтверждает ограничение 60 Гц таймером или предел CPU-copy в 20 FPS.
Счётчик входа не различает GPU render, очереди и ожидание подтверждения;
фиксированный глобальный лимит приложения этими данными не доказан.

Есть более ранний CPU resource отчёт WindowServer (00:16:36–00:18:57), где
тяжёлый стек проходит CoreDisplay::DisplayPipe::RunFullDisplayPipe → CombineLUTs
→ CurrentHeadroom / mutex. Замер счётчиков был в 00:25, поэтому это зацепка,
а не доказательство причины конкретного 20-секундного окна.

Следующий сбор — профиль стека одновременно со счётчиками, без новой установки:

    sudo bash /Volumes/1401/NullMoth-G6MF-Bridge-v6-Perf/profile-perf.sh

Скрипт запускает sample WindowServer на 20 секунд с интервалом 10 мс и текущий
исправленный collect-perf.sh. Двигать окно непрерывно по подсказке; дождаться
PROFILE COLLECTION COMPLETE. Сохранить обе новые папки profile-* и perf-*.
Если sample недоступен/отклонён, его статус и stderr сохраняются. Профилирование
добавляет наблюдательную нагрузку, выводы о точном FPS из него делать нельзя.
