# G6 MF: измерения поверх рабочего v5

NMIntelFB 0.1.4 и NVAccel 0.1.3 добавляют read-only счётчики времени.
Алгоритм вывода, fence, копирование, частота панели и EFI не меняются.
Успех v5 не означает, что новая инструментальная сборка уже проверена на ноутбуке.

Важная проверка исходника: таймер VBlank уже использует fFrameNs, измеренный
по счётчику панели. Надпись «armed (60 Hz)» была устаревшей; теперь лог содержит
настоящий заданный период. Само измерение периода при старте не изменено.

В рабочем Tahoe:

    sudo bash /Volumes/1401/NullMoth-G6MF-Bridge-v6-Perf/install-perf.sh

После PERF UPDATE READY перезагрузиться с текущим рабочим EFI, затем:

    sudo bash /Volumes/1401/NullMoth-G6MF-Bridge-v6-Perf/collect-perf.sh

Двадцать секунд непрерывно двигать окно. Сохранить весь сбор, а не только summary.
Потом вернуться в Linux. Не запускать next-stage от прошлых комплектов.

Замеры для Intel head 4:
- entry: интервалы входов performTransaction и гистограмма <7/7–12/12–20/
  20–28/28–40/>=40 мс; включает также транзакции без нового изображения;
- fence: время внутри ожидания готовности GPU, а не полная длительность GPU render;
- ready: подготовка актуальной системной копии IOSurface, включая pageoff;
- copy: только CPU copy в Intel aperture; не вся передача VRAM → RAM;
- total: весь performTransaction, включая отказы/пустые кадры;
- VBlank: заданный период, интервалы вызовов таймера и время его callback.

Все суммы в наносекундах, счётчики накопительные. Средние в summary посчитаны
по разности двух снимков; max — максимум с начала загрузки. Снимок разных
счётчиков не атомарен целиком. Idle gaps и ручная нагрузка влияют на результат;
копирования/с не являются точным FPS compositor. Таймер VBL является программным
уведомлением, не аппаратным timestamp сканирования матрицы.

Новый установщик сохраняет бэкап рабочих компонентов и Auxiliary KC. Откат:

    sudo bash /Volumes/1401/NullMoth-G6MF-Bridge-v6-Perf/rollback-bridge-macos.sh ПУТЬ_ИЗ_last-bridge-backup.txt

Если новый драйвер не даёт изображения, штатно выключить после пяти минут
автосбора и вернуться в Linux. Рабочие файлы v5 сохранены; EFI не перезаписывается.
