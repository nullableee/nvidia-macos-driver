# G6 MF: мост v5, экспериментальный тест вывода

Аппаратный тест на G6 MF успешен: интерфейс и яркость работают.
Подробности и ограничения: [результат v5](G6MF-BRIDGE-V5-RESULT-RU.md).

В v4 Tahoe распознал muxless AGDC и создал IOPresentment, но ни одного кадра
не скопировал: транзакции отклонялись с NotReady. В System KC сборки 25G241
проверено, что IOAccelDisplayPipe::init_framebuffer_resource включает active
только после получения памяти и успешного resource.prepare(). Наш v4 возвращал
NULL для Intel scanout, поэтому это условие не выполнялось.

v5 меняет NVAccel на 0.1.2. Новый NMMuxlessScanoutMemory удерживает настоящий
NMIntelFB и проверяет его актуальную геометрию и CPU-адрес. Он не предоставляет
адреса для NVIDIA GPU, не создаёт VRAM и не допускает пользовательские GPU
mapping для Intel памяти. NVResource.prepare/complete обрабатывают только этот
класс отдельно, без стандартного пути создания NVIDIA GPU mapping. Обычные
ресурсы остаются на пути базового семейства. Работает прежний fenced CPU copy.
NMI 0.1.3 и AGDC 2.6.5 сохранены из v4 без изменения их бинарников.

Патч не записывает opaque active-флаг. Его должен установить сам Tahoe после
успешной подготовки ресурса. Добавлены счётчики входов validate/performTransaction.
Проверки ASan/UBSan на mock kernel покрывают жизненный цикл, отсутствие GPU
mapping, отказ при изменении scanout, ошибки и баланс ссылки на панель.
Это не аппаратный тест успешного изображения. Возможны следующие ошибки вывода.

## Запуск

В рабочем Tahoe, загруженном через флешку 1401:

    sudo bash /Volumes/1401/NullMoth-G6MF-Bridge-v5/next-stage.sh

Скрипт проверяет комплект, тестирует настоящий NVIDIA Metal compute, сохраняет
бэкап, проверяет тестовую и рабочую Auxiliary KC и только после успеха активирует
подготовленный EFI. Он также устанавливает однократную автоматическую диагностику
следующей загрузки. Сборка на ноутбуке не нужна; пересборка KC — системная установка.
Поддержана только исследованная сборка Tahoe 25G241.

После NEXT STAGE READY перезагрузиться через 1401. Если появился рабочий стол:

    sudo bash /Volumes/1401/NullMoth-G6MF-Bridge-v5/collect-bridge.sh

Если экран чёрный, подождать пять минут для автосбора, выключить штатно, вернуться
в Linux. Не запускать next-stage повторно. Автосбор хранится на APFS в
/Users/Shared/G6MF-BootReports и копируется на USB, если том смонтирован.
Отсутствие его на флешке не означает отсутствие на APFS.

## Восстановление EFI из Linux

    python3 /run/media/spotlight/1401/NullMoth-G6MF-Bridge-v5/prepare-bridge.py --restore

Восстановление возвращает проверенный EFI с -nmintelfboff и сохраняет проблемный
EFI отдельно. Новый NVAccel остаётся установлен, NMIntelFB отключается аргументом.
Для полного отката компонентов и KC сохранён rollback-bridge-macos.sh; путь
APFS-бэкапа записан в last-bridge-backup.txt. Intel/Julionectar не удаляется.
